# iutk engine

engine made within months. stress-test/benchmark/spamtrack engine.
i worked hard for all this, please support me.

## what you need

- haxe 4.3.*
- libraries:

```
flixel: [6.2.0]
hxcpp: [4.3.2]
lime: [8.3.2]
openfl: [9.5.2]
```

## compile fnf engine

- git clone this.
- cd to the folder
- if you have everything installed, run:

```
lime test (platform, linux, windows, mac, etc) -release -64
```

once done, you can now use this engine.
